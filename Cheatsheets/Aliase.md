# Aliase

## Allgemein

| Alias | Befehl | Beschreibung |
|-------|--------|--------------|
| ll | `ls -lah` | Detaillierte Dateiliste mit versteckten Dateien |
| la | `ls -A` | Alle Dateien außer `.` und `..` anzeigen |
| cls | `clear` | Terminal leeren |

## Git

| Alias | Befehl | Beschreibung |
|-------|--------|--------------|
| gs | `git status` | Status des Repositories anzeigen |
| ga | `git add` | Dateien zur Staging Area hinzufügen |
| gc | `git commit` | Commit erstellen |
| gp | `git push` | Änderungen hochladen |
| gpl | `git pull` | Änderungen herunterladen |
| gl | `git log --oneline --graph --decorate --all` | Übersichtliche Commit-Historie |

## Navigation

| Alias | Befehl | Beschreibung |
|-------|--------|--------------|
| .. | `cd ..` | Einen Ordner zurück |
| ... | `cd ../..` | Zwei Ordner zurück |
