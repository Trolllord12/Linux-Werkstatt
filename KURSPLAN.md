# Linux-Werkstatt – Kursplan

## Kursregeln

* Der Kurs folgt einer festen Reihenfolge.
* Die Reihenfolge der Lektionen wird nicht spontan geändert.
* Neue Themen werden nur ergänzt, wenn sie sinnvoll in den Kurs passen.
* Jede Lektion wird vollständig abgeschlossen, bevor die nächste beginnt.
* Jede Lektion besteht aus:

  1. Theorie
  2. Praxis
  3. Prüfung
  4. `README.md` aktualisieren
  5. Git (`git add` → `git commit` → `git push`)
  6. Teil B (Handy / Termux)
