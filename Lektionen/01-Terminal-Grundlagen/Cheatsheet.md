# Cheatsheet – Lektion 1

| Befehl | Zweck |
|--------|-------|
| pwd | Aktuelles Verzeichnis anzeigen |
| ls | Verzeichnisinhalt anzeigen |
| ls -la | Auch versteckte Dateien anzeigen |
| cd | Verzeichnis wechseln |
| mkdir | Ordner erstellen |
| touch | Datei erstellen |
| cp | Datei oder Ordner kopieren |
| mv | Verschieben oder umbenennen |
| rm | Datei löschen |
| rmdir | Leeren Ordner löschen |
| cat | Datei komplett ausgeben |
| less | Datei seitenweise lesen |
| head | Erste Zeilen anzeigen |
| tail | Letzte Zeilen anzeigen |
| wc | Zeilen, Wörter und Bytes zählen |
| echo | Text ausgeben |
| \| | Ausgabe an nächsten Befehl weitergeben |
| > | Ausgabe in Datei schreiben (überschreibt) |
| >> | Ausgabe an Datei anhängen |
