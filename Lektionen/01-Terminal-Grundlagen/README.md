# Lektion 1 – Terminal-Grundlagen

## Lernziele

Nach dieser Lektion kannst du:

- dich sicher im Terminal bewegen
- absolute und relative Pfade unterscheiden
- Dateien und Ordner erstellen, kopieren, verschieben und löschen
- den Inhalt von Dateien anzeigen
- Pipes und Umleitungen verwenden

## Behandelte Befehle

- pwd
- ls
- cd
- mkdir
- touch
- cp
- mv
- rm
- rmdir
- cat
- less
- head
- tail
- wc
- echo

## Themen

- Navigation
- Dateien und Ordner
- Dateien lesen
- Pipes (`|`)
- Umleitungen (`>` und `>>`)
