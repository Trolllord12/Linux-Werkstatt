# Meine Notizen

- Absolute Pfade beginnen immer mit `/`.
- Relative Pfade beziehen sich auf das aktuelle Verzeichnis.
- `.` steht für das aktuelle Verzeichnis.
- `..` steht für das Elternverzeichnis.
- `mv` verschiebt oder benennt um – abhängig vom Ziel.
- `cp` erstellt eine Kopie.
- `rm` löscht Dateien dauerhaft.
- `less` eignet sich besser als `cat` für große Dateien.
- Nicht jeder Befehl kann Daten aus einer Pipe verarbeiten (`echo` zum Beispiel nicht).
- `>` überschreibt Dateien.
- `>>` hängt Daten an bestehende Dateien an.
