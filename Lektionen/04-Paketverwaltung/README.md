# Lektion 04 – Paketverwaltung

## Inhalte

- Pakete und Programme
- Paketmanager `apt`
- Paketquellen (Repositories)
- `apt update`
- `apt upgrade`
- `apt install`
- `apt remove`
- `apt autoremove`
- `apt search`

## Status

🟢 Teil A abgeschlossen

## Lernziele

Nach dieser Lektion kann ich:

- erklären, was ein Paket ist
- erklären, wofür `apt` verwendet wird
- Paketquellen erklären
- Paketlisten aktualisieren
- installierte Pakete aktualisieren
- Pakete installieren und entfernen
- nicht mehr benötigte Abhängigkeiten entfernen
- nach Paketen suchen
